# 영화 소개 서비스 스펙 (간단 버전)

## 목적
영화를 좋아하는 일반 사람들이 영화를 찾아보고, 찜하고, 리뷰를 남기는 웹 서비스.

## 사용 환경
- 웹사이트: 데스크톱, 태블릿, 모바일 웹 (반응형)

## 주요 기능
1. 영화 검색
2. 인기 영화 목록 보기
3. 영화 상세 정보 보기
4. 찜하기
5. 리뷰 (별점 + 리뷰글)
   - 공개(public) / 비공개(private) 선택
   - 다른 사용자의 공개 리뷰 열람
   - 내가 쓴 리뷰 수정/삭제

## 사용자 구분 (로그인 없음)
- 브라우저 익명 ID(A)와 닉네임 + 비밀번호(B)를 함께 사용한다.
- B가 A보다 우선한다. 다른 브라우저에서 B(닉네임 + 비밀번호)로 접근하면 같은 사용자로 승인하고, 기존 찜과 리뷰를 이어서 쓴다.

## 데이터
- 영화 정보: TMDB API (외부 API)
- 찜, 리뷰, 사용자 정보: 서버에 저장 (공개 리뷰를 공유해야 하므로)

## 기술 스택
- 프론트엔드 + 서버: Next.js (React, TypeScript)
- 스타일: Tailwind CSS
- 데이터베이스: Supabase (PostgreSQL)
- 비밀번호 저장: bcrypt 해시
- 배포: Vercel
- TMDB API 키는 서버에서만 사용한다.

## 아직 정하지 않은 것
- 비밀번호를 잊었을 때 복구 방법
- 디자인
