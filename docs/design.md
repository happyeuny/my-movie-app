# 디자인

## 디자인 도구
- Google Stitch로 화면 디자인을 만든다.
- Stitch에는 왓챠의 레이아웃(포스터를 가로로 나열한 목록 줄, 큰 대표 영화 영역 등)을 참고로 제시한다.

## 분위기
- 밝고 깔끔한 느낌 (흰색 계열 배경)
- 왓챠에서는 레이아웃만 참고하고, 색감은 밝고 깔끔한 분위기와 메인 색상을 따른다.

## 색상
- 메인 색상: `#26c7e0` (버튼, 별점, 찜 아이콘 등 강조에 사용)
- 참고: 이 색 위에 흰 글씨를 쓰면 대비가 낮아 읽기 어렵다. 메인 색 배경에는 어두운 글씨를 쓴다.

## 화면 크기
- 데스크톱, 태블릿, 모바일 웹 (반응형)

## 아직 정하지 않은 것
- 보조 색상, 글꼴
- 화면별 구성 (홈, 검색 결과, 영화 상세, 찜 목록, 관리자 화면)
